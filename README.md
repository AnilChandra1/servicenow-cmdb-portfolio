# ServiceNow CMDB Portfolio

A comprehensive portfolio showcasing my expertise in **ServiceNow Configuration Management Database (CMDB)**, **Common Service Data Model (CSDM)**, **CMDB Governance**, **Service Mapping**, **Discovery**, and **ITSM Business Analysis**. This repository contains documentation, diagrams, templates, and sample deliverables that reflect real-world enterprise practices.

---

## 📖 About the Project

The purpose of this repository is to demonstrate the knowledge and artifacts required for a **ServiceNow CMDB Analyst** or **ServiceNow Business Analyst** role.

It covers the core concepts, governance practices, and implementation approaches used to build and maintain a healthy CMDB that supports IT Service Management (ITSM), IT Operations Management (ITOM), Change Management, Incident Management, and Asset Management.
